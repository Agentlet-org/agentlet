Why Agentlet

Build once. Run anywhere.

A minimal standard for AI agents that prioritizes portability, security, and user control.

🔒

Sandboxed

Agents run in WebView sandboxes with explicit permissions. No filesystem access unless granted. CSP-enforced network limits.

👁️

Observable

Activity streams show users exactly what agents are doing. Step-by-step progress, trace logs, and cancellation support.

🧠

Inference Agnostic

Works with any LLM—Ollama, OpenAI, Anthropic, Gemini. Supports streaming, multi-turn conversations, and tool calling.

⚙️

User Configurable

Agents declare preferences in their manifest. Users customize behavior through native settings UI. No code required.

✦ New in v0.4

Connect to any tool via MCP

Model Context Protocol integration lets your agents talk to GitHub, Slack, databases, file systems, and hundreds of other tools—without writing custom integrations.

✓
Tool discovery — List and use tools from any MCP server
✓
Resource access — Read files, repos, and data via MCP URIs
✓
Subscriptions — Watch resources for real-time updates
✓
Permission model — Declare required vs optional servers
agent.js 
// Check if GitHub MCP is available
if (await bridge.mcp.isAvailable("github")) {
  
  // Get available tools
  const tools = await bridge.mcp.getTools("github");
  
  // Create an issue
  const issue = await bridge.mcp.call(
    "github", 
    "create_issue",
    { repo: "owner/repo", title: "Bug" }
  );
  
  // Or read a resource
  const readme = await bridge.mcp.read(
    "github",
    "repo://owner/repo/README.md"
  );
}

How It Works

Three steps to ship

01

Define your manifest

Declare capabilities, permissions, preferences, and actions in a single config object.

export const manifest = {
  manifest_version: "0.4",
  name: "my-agent",
  capabilities: { context: ["notes:read"], mcp: { optional: ["github"] } }
};
02

Write your actions

Export async functions that use the bridge API to access context, inference, UI, and MCP.

export async function "summarize"(input, { bridge }) {
  const notes = await bridge.selection.get();
  return await bridge.inference({ prompt: \`Summarize: \${notes}\` });
}
03

Deploy anywhere

Host your agent at a URL. Any app with the Agentlet runtime can load and run it.

const agent = await runtime.load("https://example.com/my-agent/");
await agent.invoke("summarize", {});

Bridge API

Everything you need

A minimal, powerful API surface for building sophisticated agents.

📚

bridge.context

Query, create, update, delete items in the host app

🧠

bridge.inference

LLM completions with streaming, tools, and multi-turn

🔌

bridge.mcp

Connect to MCP servers for external tools and resources

🎨

bridge.ui

Notifications, modals, forms, panels, and chat interfaces

📊

bridge.activity

Progress tracking, step logging, and trace collection

💾

bridge.storage

Persistent key-value storage scoped to your agent
